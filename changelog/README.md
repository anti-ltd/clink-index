# Clink changelog

Clink's changelog lives on the
[ANTI feedback board](https://www.anti.ltd/feedback?appId=clink&platform=ios).
Maintain release updates through the
[ANTI feedback administration interface](https://www.anti.ltd/admin?tab=feedback):

- Mark completed work **Complete** and set its **Release** field to the relevant
  version. Complete describes finished work; it does not mean the App Store
  release is live.
- New in-app feedback stays in the private inbox until a moderator publishes it.

The former GitHub project is a historical reference. Record new feedback and
release updates on ANTI.

## These files

This folder preserves historical release notes. It is no longer a publishing
source for the changelog. The existing files use the following format, with an
optional headline paragraph and `name` for the release code name:

```markdown
---
version: "1.6.2"
name: The Bad Samaritan
date: 2026-09-23
---

One or two sentences: the headline of the release.

## New

- **Key shapes.** Hexagons, circles and capsules, on any material.

## Fixed
```
