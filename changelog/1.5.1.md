Custom panels become small apps, actions can see the whole text field, and the scripting language grows up.

## New

- **Panels that can actually do something.** A custom panel used to be a layout with buttons that typed a fixed string. It is now a small app. It gets `on_action`, so a control can name something for your script to handle and work the answer out when it is tapped, instead of every outcome having to be computed while the view was being drawn. Its state is an ordinary dictionary that holds lists and dictionaries of its own, and it is handed back to you on every call, so a list you append to on one tap is still there on the next; a panel can opt into remembering it between openings and between keyboard launches. There are eleven new things to build with: a list row with a subtitle and a detail, a switch, a slider, a stepper, a segmented picker, an icon, a badge, a progress bar, a card, a wrapping row of chips, and a scrolling region of its own. And a panel can now ask the keyboard for things a returned string cannot express: type, backspace, delete a word, replace what is under the cursor, move the cursor, copy, buzz, show a brief message, or close itself. `context()` tells it what is around the cursor. Panel text fields finally work: tapping one hands it the keys, the way the notepad and Dictionary already did.
- **Actions that see more than the word you are typing.** A custom action could read the current word, the clipboard, or everything before the cursor. It can now read the selection, the line the cursor is on, the sentence it is in, the text after the cursor, or the whole field, and replacing works for all of them, including a span that straddles the cursor. An action can also call the same commands a panel can, so one action can make two edits and leave the cursor where you want it, rather than handing back a single string. Six new samples ship with it, including a regular-expression tidy-up and a bracket-the-word-and-step-inside.
- **A bigger language to write them in.** Scripts get list, set and dictionary comprehensions, `lambda`, tuples, sets, `try`/`except`/`finally`/`raise`, `global`, `del`, `is`, chained assignment with `*rest` arguments, and full f-string formatting: `f"{total:,.2f}"` lines a column of numbers up, `f"{name!r}"` quotes one. Six namespaces can be imported and nothing else: `math`, `random`, `time`, `json`, `re` and `sys`. The regular-expression engine is Clink's own rather than the system one, because it has to spend the same step budget as the rest of your script: a pattern that would otherwise run for ever ends with an error instead of a keyboard that stops answering. That budget is now uncatchable, so a runaway loop cannot swallow its own abort.
- **Themes can credit whoever made them.** A theme downloaded from a repository can now carry a link to the people behind it — an affiliate's own app or website. An ⓘ on the theme's tile opens a short card — the same one a new release announcement uses — saying who makes it and what they make, with one button to go and look. Nothing opens until you ask for it twice, the button names where it is sending you, and only a repository can attach one — a theme that reaches you by QR code, file or clipboard carries no link at all. Almost no theme has one.

## Fixed

- **Affiliate themes can be edited like any other download.** A theme from the Affiliate catalog used to be permanently read-only: no Edit, no Duplicate, no Rename, no Export, even with Pro. It now behaves exactly like an official download — free to pick and keep, and yours to change as a member. The moment you actually change one it becomes your own custom theme, which is also when the publisher's badge and their card come off it, so nobody's name ends up on colours they didn't choose. Open the builder and close it without touching anything and the theme is untouched.
- **Animated backgrounds stop disappearing.** The drifting, typing-reactive backdrop (Aurora, Rain, Starfield and the rest) used to be taken off screen whenever the keyboard came close to its memory limit — for eight seconds at a time, several times a session on a busy board, which is why it looked like the feature half-worked. It now gets smaller instead of going away: under pressure it calms down and draws itself at a fraction of the resolution rather than vanishing, and only Reduce Motion in Accessibility turns it off outright. It is also cheaper all the time — the slow wallpaper styles no longer redraw 40 times a second when nothing in them moves that fast, the three that are nothing but soft glows no longer render four times the pixels they can show, and all of them slow right down while a tool panel is covering the keyboard.
